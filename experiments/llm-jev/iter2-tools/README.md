# iteration-2 measurement tooling

The probe scripts that produced the tables of `experiments/results/llm-jev-iter2.tool.md` (harvest.sh collects the per-run records and transcripts of `bench/results/iter2-*`; metrics.py computes the per-arm rows; tables.py renders them). Run from the repository root against the archived `runs/` directories; no network, no keys.
